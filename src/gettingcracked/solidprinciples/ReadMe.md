# SOLID PRINCIPLES 
- SRP → What is this class responsible for?
- OCP → Can I extend without modifying?
- LSP → Are implementations safe to substitute?
- ISP → What capabilities should exist?
- DIP → Am I depending on abstractions?

## Quick Summary
> S → One reason to change

>O → Extend, don’t modify

>L → Subtypes must behave correctly

>I → Small, focused interfaces

>D → Depend on abstractions
